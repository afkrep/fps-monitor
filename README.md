# Трекер времени в приложениях

Небольшое приложение для Windows, которое считает, сколько времени активны разные приложения. Статистика показывается на тёмной панели: график за 7 дней, рейтинг приложений и отдельная вкладка «Приложения» со значками.

## Запуск

Скачайте `AppTimeTracker-Apps-v2.exe` и запустите двойным щелчком. Python устанавливать не нужно. Учёт запускается автоматически и работает, пока окно трекера открыто. Чтобы увидеть первые данные, переключитесь на другое приложение и поработайте в нём около 10 секунд.

## Данные и приватность

Статистика сохраняется локально в `%LOCALAPPDATA%\AppTimeTracker\activity.csv`. Приложение не отправляет данные по сети. Сам трекер не добавляется в статистику. Закрытие окна останавливает учёт.

## Сборка из исходников

Требуется Windows и компилятор .NET Framework C# (`csc.exe`). Запустите `build.ps1` в PowerShell. Сборка создаст `AppTimeTracker-Apps-v2.exe` рядом с исходником.
